# Файлы данных

Все файлы лежат в `plugins/PsyCap/`.

| Путь | Что это |
| --- | --- |
| `config.yml` | [настройки](config.md) |
| `nations.yaml` | нации, города и жители; редактируется вручную или в [веб-редакторе](../web/nations.md) |
| `online.txt` | список «играющих сейчас» ников, один на строку |
| `scenes/<код>.yml` | описание сцены: дорожки, настройки, владелец и список доступа |
| `scenetracks/<код>.scap` | дорожка сцены (окружение) |
| `recordings/<сцена>-<код>-<номер>.pcap` | дорожка игрока |
| `entitytracks/<id>.ecap` | дорожка существа |
| `fpvtracks/<сцена>-fpv-<номер>.fcap` | дорожка от первого лица |
| `playerstates/<код>.yml` | сохранённое состояние игрока (`saveplayerstate`) |

## nations.yaml

```yaml
nations:
  - name: Иглобрюхисты
    color: "#FF0000"
    bannerData: "..."      # служебное значение, задаётся командой /pcap setnationbanner
    cities:
      - name: Металлград
        players:
          - Nikita572God
          - WarlordSalad
```

Требования к файлу: уникальные названия наций; цвет вида `#RRGGBB`; уникальные названия городов в пределах нации;
ники без пробелов; хотя бы один город. Файл с ошибкой при `/pcap reload` не принимается, и остаётся прежнее
состояние. Порядок городов важен: по нему первая буква кода дорожки выбирает город (`A` — первый город файла).
Не меняйте `bannerData` вручную.

## online.txt

Один ник на строку, пустые строки игнорируются. Файл создаётся при первом запуске из случайных 100–500 ников и дальше
сам не меняется. Чтобы получить новый случайный список, выполните `/pcap regenonline` или нажмите «Сгенерировать
заново» в [редакторе](../web/nations.md#онлайн-список).

## Резервные копии

Записи — это просто файлы, поэтому достаточно копировать папку `plugins/PsyCap/`. Файлы записи пишутся целиком в
конце записи: при падении сервера во время записи она теряется.
