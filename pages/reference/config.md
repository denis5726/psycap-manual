# Настройки (config.yml)

Файл `plugins/PsyCap/config.yml`. Изменения применяются командой `/pcap reload`, кроме адресов и портов — для них
нужен перезапуск сервера.

```yaml
psycap:
  rest:
    host: '0.0.0.0'
    port: 8089
    enabled: false
  web:
    enabled: true
    host: '0.0.0.0'
    port: 8090
    code-ttl-minutes: 5
    session-ttl-hours: 12
  playback:
    melee-angle-expansion-degrees: 0
  improve:
    max-melee-turn-degrees: 25
    max-bow-turn-degrees: 12
    bow-range: 40
    shield: true
```

## `psycap.web` — веб-редактор

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | `true` | запускать ли веб-редактор. Если `false`, команда `/pcap uilogin` недоступна |
| `host` | `0.0.0.0` | на каком адресе слушать (`127.0.0.1` — только с самого сервера) |
| `port` | `8090` | порт редактора |
| `code-ttl-minutes` | `5` | сколько минут действует код входа |
| `session-ttl-hours` | `12` | сколько часов длится сессия после входа |

Редактор и API работают на одном порту, отдельной настройки CORS не требуется.

## `psycap.playback` — воспроизведение

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `melee-angle-expansion-degrees` | `0` | насколько шире записанного прицела (в градусах) может попасть удар ближнего боя при воспроизведении; `0` — выключено, максимум `60` |

В записи ближним боем сложно попасть друг по другу: NPC воспроизводит приблизительный путь, а цель — тоже запись.
Настройка расширяет область попадания: удар, который в оригинале попал, ищет цель в более широком конусе, а удар,
который промахнулся, попадает в любого, кто оказался в пределах этого угла от взгляда (до 3 блоков, без стен между).
Начните с 5–15 градусов: большие значения выглядят как чит. Применяется сразу после `/pcap reload`.

## `psycap.improve` — автоулучшение сцены

Настройки команды [`/pcap improvescene`](commands.md#pcap-improvescene).

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `max-melee-turn-degrees` | `25` | на какой максимум угла (0–90°) можно довернуть камеру, чтобы промахнувшийся удар попал; `0` — не улучшать удары |
| `max-bow-turn-degrees` | `12` | на сколько (0–45°) можно довернуть камеру, чтобы выстрел без записанного попадания попал в цель; `0` — не улучшать выстрелы |
| `bow-range` | `40` | дальность (в блоках), в пределах которой ищутся цели для выстрела |
| `shield` | `true` | поднимать ли щит тому, по кому ударили (если щит у него в левой руке) |

## `psycap.rest` — старый открытый API

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | `false` | включает **старый REST API без авторизации** на отдельном порту |
| `host` | `0.0.0.0` | адрес |
| `port` | `8089` | порт |

!!! danger "Включайте только осознанно"
    Этот порт не проверяет ни вход, ни владельца сцен: любой, кто до него дотянется, может читать и менять всё. Веб-
    редактору он не нужен. Если ключ `enabled` в вашем `config.yml` отсутствует (файл создан старой версией),
    считается `false`.

Всё остальное API с авторизацией доступно только через веб-редактор: `/api/...` на его порту.
