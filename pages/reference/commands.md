# Команды и права

Все команды начинаются с `/pcap`. Подсказки по Tab показывают только то, что вам доступно.

## Права

| Право | По умолчанию | Что даёт |
| --- | --- | --- |
| `psycap.pcap.rec` | оператор | запись, настройка сцен и вспомогательные команды |
| `psycap.pcap.play` | оператор | воспроизведение сцен и записей |
| `pct.admin` | оператор | перезагрузка настроек и онлайн-списка |

Команда `/pcap uilogin` доступна, если есть **любое** из трёх прав.

!!! note "Доступ к сцене — отдельное правило"
    Право на команду не даёт права на **чужую сцену**. Команды, принимающие код сцены, дополнительно проверяют, что
    вы владелец сцены или она разделена с вами. См. [Сцены и доступ](../web/scenes.md#доступ).

## Запись — `psycap.pcap.rec`

| Команда | Описание |
| --- | --- |
| `/pcap rectrack <сцена> <код> [игрок]` | записать игрока (по умолчанию вас) в новую дорожку; запускает сцену |
| `/pcap rectrackmulti <сцена> <код1> <игрок1> [<код2> <игрок2> …]` | записать нескольких игроков одновременно |
| `/pcap recnexttrack <сцена> <город> [immediately\|deferred]` | то же, но код дорожки подбирается по городу; `deferred` — вход позже |
| `/pcap startdeferredrec [игрок]` | начать отложенную запись |
| `/pcap stoprecall` | остановить все записи и прикрепить дорожки существ к сцене |
| `/pcap recfpv <сцена>` | записать дорожку от первого лица |
| `/pcap setregenerationpos1 <сцена>` | первый угол области отката (блок под вами) |
| `/pcap setregenerationpos2 <сцена>` | второй угол области отката |
| `/pcap possessitem` | выдать палку огня для [вселения в NPC](../possession.md) |
| `/pcap possessfpv` | вселиться в дорожку от первого лица во время `playfpv` |
| `/pcap setnationbanner <нация>` | задать баннер нации из предмета в основной руке |
| `/pcap spawnhorse <none\|leather\|iron\|gold\|diamond> <скорость>` | создать ручную осёдланную лошадь с бронёй |
| `/pcap saveplayerstate <игрок> <код>` | сохранить здоровье, голод, опыт и инвентарь игрока |
| `/pcap applyplayerstate <игрок> <код>` | применить сохранённое состояние к игроку |

## Воспроизведение — `psycap.pcap.play`

| Команда | Описание |
| --- | --- |
| `/pcap sceneplay <сцена> [мир]` | запустить сцену |
| `/pcap sceneplayfrom <сцена> <тик> [мир]` | запустить сцену с указанного тика |
| `/pcap scenestop <сцена>` | остановить сцену досрочно |
| `/pcap playfpv <сцена>` | показать сцену глазами записанного игрока (нужен мод) |
| `/pcap tpscene <сцена>` | телепортироваться к месту появления первого NPC сцены |
| `/pcap play <файл1,файл2,…>` | воспроизвести отдельные записи игроков |

## Служебные

| Команда | Право | Описание |
| --- | --- | --- |
| `/pcap uilogin` | любое из трёх | выдать одноразовый код для [входа в веб-редактор](../web/login.md) |
| `/pcap reload` | `pct.admin` | перечитать `config.yml`, `nations.yaml` и `online.txt` |
| `/pcap regenonline` | `pct.admin` | сгенерировать новый `online.txt` и применить его |

### `/pcap reload`

Перечитывает три файла независимо друг от друга. Файл с ошибкой не принимается, остаётся прежнее состояние, а в чат
приходит причина; остальные файлы это не останавливает. Адреса и порты серверов (REST и веб-редактора) читаются
один раз при запуске, и для их смены нужен перезапуск сервера.

### `/pcap regenonline`

Выбирает новые случайные 100–500 ников и записывает их в `online.txt`. Список в таб-листе игроков обновляется
сразу.
