# Установка

## Требования

| Что | Зачем |
| --- | --- |
| Paper 1.21.11 (или совместимый форк) и Java 21 | сам плагин |
| [Citizens](https://citizensnpcs.co/) | воспроизведение: NPC-игроки и NPC-существа. Без него записывать можно, воспроизводить нельзя |
| [WorldEdit](https://enginehub.org/worldedit) | откат местности в сценах (копирование и вставка области) |
| Клиентский мод PsyCap-FPV | только для [съёмки от первого лица](fpv.md) |

Citizens и WorldEdit — необязательные зависимости: плагин запустится и без них, но соответствующие команды
сообщат, что зависимости не хватает.

## Установка и первый запуск

1. Положите `PsyCap-<версия>.jar` в папку `plugins/` сервера, рядом поставьте Citizens и WorldEdit.
2. Запустите сервер. В папке `plugins/PsyCap/` появятся `config.yml`, `nations.yaml`, `online.txt` и папки для
   записей (см. [файлы данных](reference/files.md)).
3. Выдайте себе права (см. [команды и права](reference/commands.md#права)). Операторам они выдаются по умолчанию.
4. В консоли сервера найдите строку про запуск веб-редактора, например
   `Web UI listening on 0.0.0.0:8090`.

## Обновление

Замените jar и перезапустите сервер. Файлы записей старых версий плагина читаются не всегда: формат менялся. Если после
обновления записи не открываются, воспользуйтесь утилитой `convert-tracks` из дистрибутива — она умеет переводить
часть старых версий и ничего не удаляет (оригиналы остаются рядом с расширением `.bak`).

## Безопасность

- Веб-редактор доступен всем, кто может открыть порт сервера, но войти в него можно только по одноразовому коду из
  игры и только игроку с правами плагина. Подробности — в разделе [Вход](web/login.md).
- Закройте лишние порты файрволом. Если редактор не нужен, отключите его в [настройках](reference/config.md).
